BERLIN SKY TRAVEL — FREE WEBSITE
=================================

This is a plain HTML/CSS/JavaScript website. It costs $0 to host on GitHub Pages.

FILES
-----
index.html   Main website
style.css    Design
script.js    Menu, WhatsApp request form, language switcher

FREE GITHUB PAGES SETUP
-----------------------
1. Create a free account at https://github.com
2. Click "New repository".
3. Name it: berlin-sky-travel
4. Set it to Public.
5. Upload index.html, style.css and script.js.
6. Open the repository's Settings -> Pages.
7. Under "Build and deployment", choose "Deploy from a branch".
8. Choose the "main" branch and "/ (root)", then Save.
9. GitHub will give you a free address like:
   https://YOURUSERNAME.github.io/berlin-sky-travel/
